# 热柜鲜食 · 出炉与效期报损系统

便利店热柜鲜食（便当 / 饭团 / 炸物 / 包点 / 小吃）的**出炉登记 → 抽检测温 → 上柜计时 → 销售扣减 → 临期降价 → 到期/温度异常待下架 → 清点报损 → 日报**全流程。商品与销售数据均为样例。

纯 Python 3 标准库实现（SQLite + `http.server`），**零第三方依赖**。

## 一条命令启动

```bash
python3 main.py            # 默认 http://localhost:8000
python3 main.py --reset    # 清空数据,重新生成全套样例
python3 main.py --port 8080 --scale 60
```

启动后自动播种样例，并用 **30 倍速模拟时钟**在后台推进，打开页面即可陆续看到：

- 早高峰补货批次（健康在售）；
- 探头**持续超温**的饭团：连续 3 次不合格 → 自动待下架；
- **温度读数缺失**的饭团：探头失联超过 20 分钟 → 缺失留痕；
- 两个同品类**临期重叠**的便当（仅留痕一次，不重复刷）；
- 上错层位（小吃放到包点区）→ `wrong_shelf` 留痕；
- 提前售罄（效期还剩近 2 小时清空）与到期前自然售罄；
- 到期批次自动转待下架；下架清点页用触屏步进器清点后报损；
- 点「闭店」可把全部在柜批次转**闭店剩余**，再逐批清点报损；
- 历史昨夜闭店报损批次，供日报统计。

> 想手动控制节奏：`python3 main.py --no-bg`，然后 `POST /api/tick` 推进一个周期。

## 界面

七个页签，配色为象牙白 / 番茄红 / 炭灰：

| 页签 | 内容 |
|---|---|
| 制作批次 | 出炉登记、抽检温度（可附本地照片）、分配层位；批次卡显示剩余份数/状态/温度 |
| 热柜陈列图 | 按**实际层板从上到下**画成横向陈列带，每个批次同时显示**剩余份数与到期分钟** |
| 效期队列 | 在柜批次按到期分钟升序（紧迫度排序），**静态高亮、不闪烁**，可降价/销售 |
| 温度记录 | 出炉抽检 + 传感器持续读数，合格/超温着色，附件可下载 |
| 销售差异 | 销售流水（折扣价标记）+ 全量留痕事件流 |
| 下架清点 | 待下架批次 + **触屏大按钮数量步进器**，先清点（差异留痕）再确认报损；含闭店按钮与误下架撤回 |
| 日报 | 制作批次数、销售份数/额、报损份数/成本、报损原因构成 |

右上角可切换身份：**当班店员 / 值班店长**。

## 业务规则（均有测试覆盖）

1. **先测温后上柜**：出炉批次必须先记录抽检温度；不合格直接待下架，不能上柜。
2. **上柜开始计时**：到期时间 = 上柜时刻 + 商品效期。
3. **销售按批次扣减**：提交时携带 `version` 乐观锁；两人同时改同一批次数量时，旧版本提交返回 `409`，刷新后可重试。
4. **降价权限**：
   - 店员：仅**临期**批次、仅商品的**预设折扣**（如 8 折 / 7 折）；
   - 店长：可设例外价格，但非临期/例外折扣需二次确认。
5. **自动待下架**：到期，或温度连续 3 次不合格。
6. **报损不可逆**：待下架 → 员工实物清点（账实差异留痕）→ 确认报损；已报损不能销售、不能重复报损、不能撤回。
7. **误下架撤回**：仅 `pending` 且未真正到期/报损的批次可撤回上柜并留痕。
8. **全量留痕**：温度缺失、上错层位、数量差异、提前售罄、临期重叠、误下架、闭店剩余、超容量等都写入 `audit_events`。

## 数据与进程

- `data/hotfood.db`：SQLite，保存门店、商品、层位、批次、温度读数、销售、调价、审计事件。
- `data/attachments/`：抽检附件（上传的原始字节，按门店/UUID 存储）。
- 进程内守护线程 `BackgroundTask`：每 2 秒一个 tick，调用 `scan_expiry` 计算临期/到期/缺失，并通过模拟适配器拉取温度与销售回执。
- `app/adapters.py`：`TemperatureAdapter`（正弦波动 + 可编排超温/失联）与 `SalesAdapter`（份/小时速率的泊松抽样 + 可编排提前售罄）。

```

覆盖：批次扣减、并发修订（销售与数量调整两条路径）、效期边界（25 分钟临期与到期精确边界）、温度连续不合格/缺失阈值、折扣权限（店员预设/店长例外）、报损不可逆、误下架撤回、临期重叠只留痕一次、闭店剩余、日报聚合，以及后台模拟与 HTTP 全链路集成测试。

app/adapters.py         模拟温度探头 / POS 销售回执适配器
app/tasks.py            模拟时钟 + 进程内后台 tick 线程
app/seed.py             全套样例场景
app/web.py              JSON API 与静态资源路由
app/static/             index.html / app.js / styles.css
tests/                  领域测试 + 模拟/HTTP 集成测试
```
