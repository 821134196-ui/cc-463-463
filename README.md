# 便利店热柜鲜食出炉与效期报损系统

面向单店热柜（保温柜）鲜食的**出炉登记 → 抽检测温 → 分层位计时 → 销售扣减 →
临期降价 → 到期/温度异常自动下架 → 清点报损 → 日报**全流程。商品与销售数据
均为样例。

- **零第三方依赖**：仅使用 Python 3 标准库（`sqlite3` / `wsgiref` / `unittest`）。
- SQLite 保存批次与库存，抽检附件落本地目录，进程内定时任务计算临期/到期，
  模拟适配器持续回传温度读数与销售回执。
- 界面主色：象牙白 `#FAF6EC`、番茄红 `#D23B3B`、炭灰 `#2B2D2F`。

## 一条本地命令启动

```bash
./run.sh            # 等价于 python3 run.py：重建样例数据并启动
# 可选： --port 8000   --keep-data（保留现有数据）
```

打开 http://127.0.0.1:8000/ ，右上角切换当班身份：

- **店员 clerk01**：只能在授权窗口内执行预设折扣（剩余 ≤20 分 9 折、≤10 分 7 折）。
- **店长 manager01**：可输入任意折扣率作为“例外价”，负责闭店与例外处理。

启动后即处于营业中状态，后台每几秒模拟一次温度探头与 POS 销售回执。

### 样例覆盖的场景

| 批次 | 场景 |
|---|---|
| A01–A04 | 午间高峰补货、正常在售、陆续有销售 |
| N01 / N02 | 同品两批**临期重叠**（自动留痕），N02 已由店员执行 9 折 |
| T01 | 已连续 2 次低温，适配器再回传 1 次不合格即**自动转待下架** |
| M01 | 出炉抽检**温度读数缺失**，卡住不能上柜（留痕） |
| R01 | 抽检合格、待分配层位 |
| W01 | 曾尝试把面点放进炸物层（**上错层位**被拒并留痕），后归位 |
| E01 | 已过效期，定时任务**到期自动转待下架** |
| H01–H04 | 早高峰闭店剩余：含**账实数量差异**、**提前售罄**、已报损与待清点 |

## 七个页面

制作批次 · 热柜陈列图（按真实层板的横向陈列带，每批同时显示剩余份数与到期
分钟）· 效期队列（按到期紧迫度升序，**不闪烁**）· 温度记录（温区带折线图 +
明细表）· 销售差异（销售回执与异常留痕）· 下架清点（**触屏大步进器**清点份数）
· 日报。

## 核心规则

- **批次出炉后先测温**：温度落在商品温区才允许分层位；分层位时刻开始计时，
  `到期时间 = 上柜时间 + 标准效期`。
- **销售按批次扣减**：售出即写销售回执并扣减该批 `remaining`；扣到 0 记为
  “提前售罄”并留痕；超卖、对非在售批次销售一律拒绝。
- **乐观锁**：批次带 `version`，两人同时改同一批数量/价格/清点时，后提交者
  若基于旧版本会收到 `409 version_conflict`，刷新后才能提交。
- **折扣权限**：店员只能执行预设阶梯折扣且须到达对应时点；例外价格仅店长可用，
  每次降价均留痕（预设/例外、操作角色）。
- **自动待下架**：到达到期时刻，或连续 3 次保温温度不合格，批次自动转
  “待下架”。人工误下架且尚未到期可“撤销误下架”（留痕）；到期/温度/闭店批次
  不可撤销，必须清点。
- **报损不可逆**：员工触屏清点实有份数后确认报损；账实不符自动留痕；已报损
  批次不能恢复销售、不能二次报损。
- **七类留痕**：温度读数缺失、上错层位、批次数量差异、提前售罄、临期重叠、
  误下架、闭店剩余（另含到期、温度失效、降价留痕）。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：批次扣减与超卖拒绝、并发修订旧版本失败（服务层 + HTTP 409）、效期边界
（到期前 1 秒可售 / 到期时刻拒售并自动下架 / 临期阈值边界）、折扣权限
（店员预设窗口、提前拒绝、非预设拒绝、店长例外价）、报损不可逆、连续温度
不合格、错层位、误下架撤销、闭店剩余、附件上传与多线程不超卖。

## 目录结构

```
hotcab/
  config.py       常量：温区规则、临期阈值、折扣阶梯、节拍、主题色
  clock.py        可注入时钟（测试 FakeClock / 种子 OffsetClock）
  database.py     SQLite schema、连接工厂、进程内写锁
  service.py      领域服务：批次生命周期/乐观锁/效期/温度/折扣/报损/审计/日报
  adapters.py     模拟温度探头与 POS 销售回执（确定性随机，可复现）
  scheduler.py    进程内定时任务（效期、温度、销售）
  seed.py         主数据与高峰/温度异常/闭店报损样例
  webapp.py       零依赖 WSGI 应用 + JSON API
  web/            index.html / app.css / app.js（原生 JS，轮询不闪烁）
run.py / run.sh   一条命令生成样例并启动
tests/            unittest 测试
data/             运行期生成：hotcab.db 与 attachments/（已 gitignore）
```
